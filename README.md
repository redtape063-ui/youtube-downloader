# 🎬 YouTube Downloader 웹 애플리케이션

유튜브 동영상 및 MP3 음원을 손쉽게 다운로드할 수 있는 모던 웹 애플리케이션입니다.

## ✨ 주요 기능
- **영상 정보 미리보기**: 썸네일, 영상 제목, 채널명, 재생 시간, 조회수 표시
- **고화질 비디오 다운로드**: 1080p FHD, 720p HD, 480p 등 원하는 해상도로 MP4 다운로드 (오디오 자동 병합)
- **고음질 오디오 추출**: 원클릭으로 192kbps MP3 음원 파일 추출
- **실시간 진행률 표시**: 다운로드 진행률(%), 다운로드 속도 및 예상 완료 시간(ETA) 안내
- **자동 정리**: 다운로드 완료 후 일정 시간이 지난 임시 파일은 자동으로 정리되어 디스크 공간 절약

## 🚀 실행 방법

### 1. 웹앱 실행
터미널에서 아래 명령어를 실행하세요:

```bash
cd /Users/sojunsu/.gemini/antigravity/scratch/youtube-downloader
./run.sh
```

또는 직접 Python으로 실행:
```bash
python3 app.py
```

### 2. 브라우저 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **http://127.0.0.1:5050**
